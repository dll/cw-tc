帮助

常见问题与使用指引。若未解决，请见 联系我们。

如何登录？

学生、教师、管理员使用同一套账号体系：登录账号为手机号，密码由平台签发或自行设置。首次使用请通过登录页的验证码流程激活。

学生端常见问题

  • 选课/学习：登录后进入「我的课程」浏览与学习。
  • 测评：进入测评后计时以服务端为准；断线重连后剩余时间由服务端计算（支持断线续考）。
  • 证书：通过测评后可在线查看/下载证书，并可在验真页核验。

教师端常见问题

  • 课程、题库、组卷、批阅与成绩分析见 教师端。

管理端常见问题

  • 用户、订单、发证与运营管理见 管理端。

浏览器与设备

推荐使用 Chrome / Edge / Safari 等现代浏览器。学生端同时提供移动端（Android）。
