# 支付入驻操作手册（微信支付 / 支付宝）

> 目的：拿已齐备的资质材料，在**微信支付**与**支付宝**两个平台完成商户入驻、下号，
> 并拿到代码所需的**商户号 / AppID / 密钥 / 证书 / 回调地址**。
> 下号后把结果回填到 `docs/交付信息.md` §二 / §三，即可接通真实支付。
>
> **配套材料**（已就位，见 `data/支付信息/`）：
> `01营业执照.jpg` · `02法定代表人身份证（正面/反面）.jpg` · `03对公银行账户.jpg` · `03开户证明.jpg`
> 另需：微信超管微信号 + 手机号、支付宝企业账号（见 `data/支付信息/04其它企业资质.txt`）。
>
> ⚠️ 平台界面会改版，以下「入口 / 菜单名」以**操作当天平台实际界面为准**；
> 但**每一步要拿到什么产物**（商户号、AppID、密钥、证书）是固定不变的，照做即可。

## 一、微信支付入驻（Native 扫码 + App 支付）

### 1.1 注册微信支付商户号（企业）

**入口**：电脑打开 `https://pay.weixin.qq.com`（微信支付商户平台），点「注册微信支付商户号」；
也可用微信搜小程序「**微信支付商家助手**」。

1. 主体类型选 **「企业」**（营业执照）。
2. 填写**商家超级管理员**信息：
   - 姓名、**手机号**（接收验证码）、邮箱；
   - **微信号**（即 `04其它企业资质.txt` 里的超管微信号，须真实可登录、能扫码）。
3. 填写**主体信息**：
   - 上传 `01营业执照.jpg`；
   - 填写统一社会信用代码、营业执照有效期、经营范围（经营类目报 **在线教育/教育**）。
4. 填写**法人信息**：上传 `02法定代表人身份证（正面/反面）.jpg`。
5. 填写**结算账户**：`03对公银行账户.jpg` + `03开户证明.jpg` 的户名、账号、开户行。
6. **法人验证**（二选一）：
   - 方式 A「法人微信验证」：法人用本人微信扫码做人脸识别（最快）；
   - 方式 B「对公账户打款验证」：微信向对公账户打一笔小额款，回填金额（1-2 天）。
7. 签署《微信支付服务协议》，提交审核。

**审核**：通常 1-7 个工作日（常见 1-2 天）。通过后收到短信/邮件通知。

> **产物**：`商户号（mch_id）`—— 10 位数字，即 `.env` 的 `CWTC_WXPAY_MCH_ID`。

### 1.2 配置 APIv3 密钥与 API 证书（下号后必须做）

登录商户平台 → 「**账户中心 → API安全**」：

1. **设置 APIv3 密钥**：点「设置 APIv3 密钥」，自定一个 **32 位**字符串（建议 `openssl rand -hex 16` 生成，或随机 32 字符）。
   → 即 `.env` 的 `CWTC_WXPAY_API_V3_KEY`。**请妥善保存，只写服务器 `/opt/cw-tc/shared/.env`，不入库。**
2. **申请 API 证书**：点「申请 API 证书」，下载得到：
   - `apiclient_key.pem`（**商户私钥**）→ 即 `.env` 的 `CWTC_WXPAY_PRIVATE_KEY_PATH` 指向的文件；
   - **证书序列号（serial_no）** → 即 `.env` 的 `CWTC_WXPAY_SERIAL_NO`。
3. （可选）下载**平台证书**用于回调验签，后续按需。

> **产物**：`APIv3密钥` + `apiclient_key.pem` + `证书序列号`。

### 1.3 开通 Native 支付（网站扫码，需要服务号 AppID）

微信 **Native 支付**（用户扫码支付）需要绑定一个**已认证的服务号**提供 AppID：

1. 若尚无服务号：到微信公众平台 `https://mp.weixin.qq.com` 注册「**服务号**」（企业），
   完成**微信认证**（认证需营业执照，收 300 元/年）。
2. 拿服务号的 **AppID**（公众号后台 → 设置与开发 → 基本配置）。
3. 回商户平台 → 「**产品中心 → 我的产品**」→ 开通「**Native支付**」→ 关联该服务号 AppID。

> **产物**：`CWTC_WXPAY_APP_ID`（Native 用服务号 AppID）。

### 1.4 开通 App 支付（Android，需要开放平台移动应用 AppID）

1. 到微信开放平台 `https://open.weixin.qq.com` 注册并认证「**移动应用**」：
   - 应用名称、图标、简介；
   - **Android 包名**：`cn.ccit.cwtc`；
   - **应用签名 MD5**（用正式签名 APK 的签名 MD5，见下方「签名 MD5 怎么取」）。
2. 移动应用审核通过后获得 **AppID**。
3. 回商户平台 → 「产品中心」→ 开通「**App支付**」→ 关联该移动应用 AppID。

> **产物**：App 支付的 AppID（若与 Native 服务号 AppID 不同，需在代码里区分场景）。
> 我们的配置里 `CWTC_WXPAY_APP_ID` 首发填**服务号 AppID**（Native 主场景）；App 支付 AppID 在 App 端单独维护。

#### 附：Android 签名 MD5 怎么取（App 支付登记用）

```bash
# 用 keytool 从签名 keystore 取（keytool 在 JDK 里）
keytool -exportcert -keystore <签名密钥库.jks> -alias <别名> \
  | xxd -p | tr -d '\n' | tr 'A-F' 'a-f'
# 微信 App 支付需要的是去掉冒号、全小写的 MD5
```

## 二、支付宝入驻（当面付 + App 支付）

### 2.1 注册 / 确认企业支付宝账号

- 支付宝企业账户须以**营业执照完成企业实名认证**（主体 = 滁州畅网智能科技有限公司）。
- 若 `04其它企业资质.txt` 里的手机号已是**企业支付宝**，直接用它登录 `https://open.alipay.com`；
  若是个人支付宝，需先完成「**企业认证**」（上传营业执照 + 对公打款验证）。

> ⚠️ **务必确认是企业账户**（登录后账户主体显示公司名），个人账户不能用于企业收款。

### 2.2 入驻开放平台并创建应用

1. 登录 `https://open.alipay.com`（支付宝开放平台）。
2. 「**创建应用**」：
   - 网页场景 → 创建「**网页/移动应用**」；
   - Android 场景 → 绑定移动应用（包名 `cn.ccit.cwtc`）。
3. 应用创建后获得 **AppID**（16 位数字）。

> **产物**：`CWTC_ALIPAY_APP_ID`。

### 2.3 配置密钥（应用私钥 + 支付宝公钥）

1. 下载官方「**支付宝开放平台密钥工具**」（开放平台 → 开发工具下载）。
2. 用工具生成 **RSA2（2048 位）** 密钥对：
   - **应用私钥**：自己保存（即 `.env` 的 `CWTC_ALIPAY_PRIVATE_KEY_PATH` 指向的文件）；
   - **应用公钥**：填到开放平台「应用 → 开发设置 → 接口加签方式」。
3. 平台用应用公钥生成 **支付宝公钥**，从平台**下载**（即 `.env` 的 `CWTC_ALIPAY_PUBLIC_KEY_PATH` 指向的文件）。

> **产物**：`应用私钥(.pem)` + `支付宝公钥(.pem)`。

### 2.4 开通产品（当面付 + App 支付）

1. 「**产品中心**」→ 开通「**当面付**」（扫码/二维码收单）→ 签约；
2. 开通「**App 支付**」→ 签约（需移动应用已绑定、已上架信息）。

> 回调地址（签约/应用里填）：`https://cw-tc.ccit-agent.cn/api/v1/pay/alipay/notify`。

## 三、下号后回填清单（对应 `.env` 变量）

### 微信支付（写服务器 `/opt/cw-tc/shared/.env`）

| 变量 | 取值来源 |
|---|---|
| `CWTC_WXPAY_MCH_ID` | 商户号（10 位） |
| `CWTC_WXPAY_APP_ID` | 服务号 AppID（Native） |
| `CWTC_WXPAY_API_V3_KEY` | APIv3 密钥（32 位，自行设置） |
| `CWTC_WXPAY_SERIAL_NO` | 商户 API 证书序列号 |
| `CWTC_WXPAY_PRIVATE_KEY_PATH` | `/opt/cw-tc/shared/wxpay_apiclient_key.pem` |
| `CWTC_WXPAY_NOTIFY_URL` | `https://cw-tc.ccit-agent.cn/api/v1/pay/wechat/notify` |

### 支付宝

| 变量 | 取值来源 |
|---|---|
| `CWTC_ALIPAY_APP_ID` | 应用 AppID（16 位） |
| `CWTC_ALIPAY_PRIVATE_KEY_PATH` | `/opt/cw-tc/shared/alipay_app_private_key.pem` |
| `CWTC_ALIPAY_PUBLIC_KEY_PATH` | `/opt/cw-tc/shared/alipay_public_key.pem` |
| `CWTC_ALIPAY_NOTIFY_URL` | `https://cw-tc.ccit-agent.cn/api/v1/pay/alipay/notify` |
| `CWTC_ALIPAY_GATEWAY` | `https://openapi.alipay.com/gateway.do` |

## 四、关键注意事项

1. **经营类目**：一律报「在线教育 / 教育」，不要报「虚拟充值」（会被驳回或事后整改）。
2. **结算账户**：对公账户，与开票主体（滁州畅网智能科技有限公司）一致。
3. **回调地址必须公网 HTTPS**：`cw-tc.ccit-agent.cn` 需已上线并挂好 TLS（备案已闭环，主/子域均腾讯云）。
4. **密钥不进仓库**：所有私钥/密钥只放服务器 `/opt/cw-tc/shared/`（`chmod 600`），证书私钥文件同名即可。
5. **法人验证**：优先走「法人微信扫脸」（微信侧）与「对公打款」（支付宝侧），不用来回寄纸质。
6. **两渠道可并行提交**：微信与支付宝互不影响，同时入驻省时间。

## 五、常见坑

| 坑 | 说明 |
|---|---|
| 支付宝用了个人账户 | 个人支付宝不能企业收款，必须先做企业认证 |
| 微信 App 支付签名不匹配 | 包名 `cn.ccit.cwtc` 或签名 MD5 与登记不一致，直接报签名错误 |
| Native 支付没服务号 AppID | Native 必须绑公众号 AppID，不能拿开放平台移动应用 AppID 顶替 |
| APIv3 密钥不是 32 位 | 平台会拒绝，必须正好 32 字符 |
| 回调地址不是 HTTPS | 微信/支付宝都会拒绝回调配置 |
