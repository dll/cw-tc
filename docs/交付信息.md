# 第三课堂 · 交付信息清单（M2 支付接入）

> **本文是什么**：为接通 M2 真实支付（微信支付 Native/App + 支付宝当面付/App）列出**必须由公司/刘老师提供或决策的全部信息**，逐项对齐环境变量名与存放位置。
> **本文不是什么**：不是技术实现方案（见 `docs/M2-支付接入要求-v1.md`），也不是需求（见 PRD §7.3 / §9.7）。
>
> **状态**：技术侧已就绪 —— 下单/价格快照/回调验签/幂等/权益开通/退款/对账/订单超时关闭已全部实现并测试；**下号后只换密钥与证书、改配置，不改代码**。
> **唯一硬卡点 = 企业资质与商户号审批周期**（不是技术问题）。

## 〇、安全约定（先读）

| 规则 | 说明 |
|---|---|
| **真实值绝不进仓库** | 所有密钥/证书/商户号只写服务器 `/opt/cw-tc/shared/.env`（`chmod 600`）；证书私钥文件放 `/opt/cw-tc/shared/`。仓库只保留 `deploy/.env.example` 模板。 |
| **提供方式** | 请把值填到本文对应表格，或直接落到服务器 `shared/.env`（**不要**发在群聊/提交到 git）。 |
| **密钥生命周期** | 加密/签名类密钥（身份证密钥、HMAC、会话）**一旦启用不可更换**；支付证书/密钥**需支持轮换**。 |

## 二、微信支付（Native 扫码 · Web / App 支付 · Android）

### 2.1 需要提供的值（对应 `.env` 变量）

| 环境变量 | 说明 | 格式 / 生成方法 | 状态 |
|---|---|---|---|
| `CWTC_WXPAY_MCH_ID` | 商户号 | 10 位数字 | ⬜ |
| `CWTC_WXPAY_APP_ID` | 公众号/移动应用 AppID（Native 用服务号，App 用开放平台移动应用） | `wx` 开头 | ⬜ |
| `CWTC_WXPAY_API_V3_KEY` | APIv3 密钥 | **32 位**，平台自行生成（`openssl rand -hex 16`） | ⬜ |
| `CWTC_WXPAY_SERIAL_NO` | 商户 API 证书序列号 | 从商户平台下载证书后取得 | ⬜ |
| `CWTC_WXPAY_PRIVATE_KEY_PATH` | 商户私钥文件路径 | `apiclient_key.pem`，放 `/opt/cw-tc/shared/` | ⬜ |
| `CWTC_WXPAY_NOTIFY_URL` | 回调地址（**必须 HTTPS 公网可达**） | `https://cw-tc.ccit-agent.cn/api/v1/pay/wechat/notify` | ⬜ |

### 2.2 证书文件

| 文件 | 说明 | 存放位置 |
|---|---|---|
| `apiclient_key.pem` | 商户 API 私钥（对应证书序列号） | `/opt/cw-tc/shared/wxpay_apiclient_key.pem` |
| 平台证书（可选） | 验证回调签名（微信侧平台证书） | `/opt/cw-tc/shared/` |
