# 课程导入 v1.0

> 适用范围：管理员在「课程管理 → 导入新课程」导入**平台课程**（`source='platform'`）。
> 上游课程仍由 `cmd/sync` 只读同步；两者**不得混用**（AGENTS 铁律 1）。

## 1. 两种来源，两条路径

| 来源 | 入口 | 事实源 |
|---|---|---|
| `upstream` 上游课程 | `go run ./cmd/sync`（按 `source` 过滤，只读覆盖） | `AI化教学创新/` |
| `platform` 平台课程 | 管理后台「导入新课程」/ `POST /admin/courses/import` | 平台自身 |

本文只讲 **platform 导入**。导入结果是 **`building` 草稿**，**不会自动上架**，仍需走课程审核。

## 2. 资源包（ZIP）

管理后台直接上传 ZIP，**不再需要先登录服务器把文件放进 `imports/`**。

```
course.zip
├── manifest.json               # 必须在包根目录
├── 01/
│   ├── notes.md
│   ├── video.mp4
│   └── slides/                 # HTML 目录（整目录复制）
│       ├── index.html
│       └── assets/
│           ├── app.css
│           └── cover.png
└── 02/
    └── audio.mp3
```

- 允许整包外面再套**唯一一层目录**（例如 `PY-101/manifest.json`），服务端会自动定位。
- 清单里的 `path` **只能写相对路径**，相对 `manifest.json` 所在目录，不能 `../` 越界。
- HTML 目录必须以 `index.html` 或 `index.htm` 为入口；`assets/` 下的图片 / CSS / JS / 字体随目录复制，并通过 HTML 的 `inline_base_url` 受控提供。
- 文件名会进入 COS / 内容目录的对象键：`courses/{course_code}/lectures/{no}/{kind}/{filename}`。
- 上传上限 1 GB；解压后总量 2 GB、单文件 1 GB、文件数 5000（防 zip bomb / 恶意包）。
- 旧方式（预先上传到服务器 `ContentDir/imports/<source_root>/` 后调 JSON 接口）仍保留给脚本，管理后台不再使用。

## 3. 导入清单

```json
{
  "course_code": "PY-101",
  "name": "Python 入门",
  "intro": "面向零基础的平台课程",
  "line": "main",
  "major_id": 1,
  "price_cents": 9900,
  "teacher_id": 2,
  "source_root": "PY-101",
  "lectures": [
    {
      "no": 1,
      "title": "第一讲",
      "is_preview": true,
      "assets": [
        { "title": "讲义", "path": "01/notes.md" },
        { "kind": "video", "title": "视频", "path": "01/video.mp4" },
        { "kind": "html", "title": "课件", "path": "01/slides" }
      ]
    },
    {
      "no": 2,
      "title": "第二讲",
      "assets": [
        { "kind": "audio", "title": "音频", "path": "02/audio.mp3" }
      ]
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `course_code` | ✅ | 2~32 位字母 / 数字 / `_` / `-`；**唯一**，重复导入返回 409 |
| `name` | ✅ | 课程名 |
| `line` | | `main`（默认）/ `aux` |
| `price_cents` | | 分；默认 0 |
| `teacher_id` | ✅ | **平台课程必须有归属教师**（DB CHECK）；填 `staff.id`，角色应为教师 |
| `major_id` | | 专业 id；可空 |
| `source_root` | | 仅旧版 JSON 导入使用；上传 ZIP 时忽略（固定为清单所在目录） |
| `lectures[].no` | ✅ | 讲次号，正整数且不重复 |
| `lectures[].title` | ✅ | 讲次标题 |
| `lectures[].is_preview` | | 是否单讲试学 |
| `assets[].path` | ✅ | 相对 `source_root` 的文件或 HTML 目录 |
| `assets[].kind` | | 留空则按扩展名推断；显式值见下表 |
| `assets[].title` | | 留空取文件名 |

### 资源类型与落库方式

| `kind` | 典型扩展名 | 存储 |
|---|---|---|
| `html` | `.html` / `.htm` / **目录** | 本地 `ContentDir`（目录整包复制，含 `assets/`） |
| `markdown` | `.md` / `.markdown` | 本地 `ContentDir` |
| `video` | `.mp4` / `.mov` / `.m4v` | **配置 COS 时上传 COS**；否则本地 |
| `audio` | `.mp3` / `.wav` / `.m4a` / `.flac` / `.aac` | 同 video |
| `slide` | `.pdf` / `.ppt` / `.pptx` / `.key` | 本地 `ContentDir` |
| `code` | `.py` / `.js` / `.ts` / `.go` / `.java` / `.c` / `.cpp` / `.rs` / `.sh` / `.sql` | 本地 `ContentDir`（下载名保留） |
| `frozen_output` | `.json` | 本地 `ContentDir` |

> `CWTC_MEDIA_FORCE_FILE=true` 时，即使配置了 COS，MP4 / 音频也回落本地，便于应急。

## 4. 调用方式

管理后台：**课程管理 → 导入新课程**，选择 ZIP 资源包（可另选归属教师覆盖清单里的 `teacher_id`），确认后上传。

接口（推荐）：

```http
POST /api/v1/admin/courses/import-package
Authorization: Bearer <admin token>
Content-Type: multipart/form-data

file=<course.zip>
teacher_id=2        # 可选
```

旧版接口（兼容 / 脚本，资源需预先放在服务器 `ContentDir/imports/`）：

```http
POST /api/v1/admin/courses/import
Authorization: Bearer <admin token>

{
  "confirm": true,
  "manifest": { "...": "见上" }
}
```

响应：

```json
{
  "code": 0,
  "data": {
    "course_code": "PY-101",
    "name": "Python 入门",
    "lectures": 2,
    "assets": 4,
    "storage_keys": ["courses/PY-101/lectures/1/markdown/notes.md", "..."],
    "status": "building",
    "package": "course.zip",
    "package_sha256": "...",
    "note": "已导入为平台课程草稿；请核对内容后走审核上架流程"
  }
}
```

## 5. 校验与失败

- 先安全解压 ZIP（拒绝路径穿越 / 符号链接 / 超限包），再校验清单与资源；
- 课程码重复、资源缺失、路径越界、未知资源类型、HTML 目录缺少入口、清单 JSON 非法 → **400 / 409**，接口返回具体原因；
- 文件先复制 / 上传，再在**一个事务**里写 `course` / `lecture` / `asset`；事务失败会清理本地已复制文件，临时解压目录随请求结束删除；
- 所有导入写 `audit_log`（`action=course.import`，含包名、大小与 SHA-256）；
- 导入完成后请核对讲次数、资源类型与试学设置，再执行审核与上架。

## 6. 删除课程

管理后台：**课程管理 → 删除**（仅 `source=platform` 且非「已上架」的课程显示）。

约束：
- 必须填写删除事由并二次确认；
- **已上架课程必须先下架**；
- 已有订单 / 学习权益 / 测评记录 / 成绩 / 证书的课程**不可删除**（请下架保留）；
- 软删除：`course.deleted_at` 置位，列表与对外接口过滤；写 `course_delete_log` 与审计；相关运营位同步置 `removed`；
- 上游课程由 `cmd/sync` 维护，后台不允许手工删除。
