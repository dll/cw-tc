## 5. 密钥

`/opt/cw-tc-staging/shared/.env`（chmod 600，属主 ubuntu）：

- 强制密钥（服务启动校验）：`CWTC_ID_CARD_ENC_KEY`（**恰好 32 字符**）· `CWTC_ID_CARD_HMAC_KEY` · `CWTC_SESSION_SECRET`（≥32 字符）。
  - ⚠️ **HMAC / SESSION 必须离线备份**（HMAC 一旦启用不可更换）。
- DB/Redis 连接、`CWTC_PUBLIC_ENTRY=https://cw-tc.ccit-agent.cn`、日志脱敏开关等。

## 7.1 服务器端构建与部署（推荐）

服务器已具备**拉代码→构建→部署**能力（不再依赖本机交叉编译）：

- 构建目录：`/opt/cw-tc-build/repo`（`git clone dll/cw-tc`，只读部署密钥 `cw-tc-server-build`）
- 部署脚本：**`/opt/cw-tc-build/deploy-staging.sh`** —— 拉最新 `main` → `CGO_ENABLED=0 GOOS=linux go build` → 组装 release → 软链 `current` → `systemctl restart cw-tc-staging` → 健康检查
- 工具链：服务器已装 **Go 1.26.0**（`/usr/local/go`）；`GOPROXY=https://goproxy.cn`

```bash
ssh -i ~/.ssh/cw-vopc-deploy ubuntu@129.211.223.113
bash /opt/cw-tc-build/deploy-staging.sh
```

**自动部署**：`.github/workflows/deploy-staging.yml` —— CI（`CI Quality Gate`）在 `main` 通过后，SSH 到服务器执行上述脚本（也可手动 `workflow_dispatch`）。所需 GitHub Secrets：`DEPLOY_HOST` / `DEPLOY_USER` / `DEPLOY_SSH_KEY`。
