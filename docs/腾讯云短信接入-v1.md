# 腾讯云短信接入 v1.0

> 适用范围：注册 / 登录 / 重置密码 / 换绑手机号 / 登录页申诉的**短信验证码发送**。
> 站内「消息中心」「事务通知」「广播」是系统内通讯，**与本渠道相互独立，继续保留，不受影响**。

- 腾讯云短信**签名尚未审核通过**；模板创建必须先选择已审核签名，因此**模板也无法进入审核**；
- 本机 `.env` 已置空 `CWTC_SMS_PROVIDER`，短信发送 **fail-closed（503）**，不会发起真实调用；
- 站内消息、管理员重置码、身份证验证重置、既有账号密码登录**不受影响**；
- 暂停期间**不要**填写占位模板 ID、**不要**做发送测试，避免误判为“代码故障”或产生无意义调用；
- 当前 `CWTC_SMS_SECRET_ID=cw-tc` 也不是腾讯云格式（应为 `AKID` + 32 位），恢复前必须一并更换。

恢复顺序（不可颠倒）：

1. 提交签名并等待审核通过；
2. 用**已审核签名**提交验证码模板（单变量 `{1}`）并等待审核通过；
3. 创建/更换 CAM 子账号 SecretId、SecretKey；
4. 回填真实 `CWTC_SMS_TEMPLATE_ID`（**不是** `1234567`）；
5. 恢复 `CWTC_SMS_PROVIDER=tencent`，重启服务；
6. 按第 4 节验证清单测试一次真实收发。

## 1. 已完成的部分

- 后端已实现腾讯云短信 **TC3-HMAC-SHA256** 签名，不依赖厂商 SDK；
- 配置齐全时调用 `SendSms`；未配置时 **fail-closed**（503），不会假装已发送；
- 发送前必须先过图形验证码；
- 单手机号 **60 秒冷却**、**每日 10 条**；单 IP **每小时 20 次**（多实例需 Redis 共享计数，见 [`Redis限频接入-v1.md`](Redis限频接入-v1.md)）；
- 发送失败会撤销刚生成的验证码，避免“发送失败但码仍有效”；
- 验证码只哈希保存在内存并 10 分钟过期，**不写日志、不返回给客户端**。

## 2. 腾讯云控制台必做步骤

1. **账号与实名**
   - 注册腾讯云账号并完成**企业实名认证**（个人实名通常也能开通，但生产建议企业主体）。
2. **开通短信服务**
   - 控制台 → 短信 SMS → 开通服务；确认账号可用短信区域。
3. **创建应用**
   - 短信控制台 → 应用管理 → **创建应用**；
   - 记录 **SDK AppID**（如 `1400xxxxxx`）。
4. **申请短信签名**
   - 签名管理 → 创建签名；建议使用公司主体名（与证书签发主体一致）；
   - **必须等审核通过**；未通过前无法申请模板；
   - 记录审核通过的 **签名内容**（例如 `畅网智能科技`）。
5. **申请短信模板（前置：签名已审核通过）**
   - 模板管理 → 创建正文模板，**选择第 4 步已审核的签名**；
   - **只使用一个变量** `{1}` 表示 6 位验证码，例如：
     `您的验证码为{1}，10分钟内有效，请勿泄露。`
   - 记录审核通过的 **模板 ID**；`1234567` 只是文档占位，**不是真实 ID**。
   - ⚠️ 本实现 `TemplateParamSet` **只传一个参数（验证码）**；若模板有多个变量，需先改代码 / 配置，不要直接上线。
6. **创建 API 密钥（最小权限）**
   - 访问管理 CAM → 用户 → 新建**子用户**（不要用主账号密钥）；
   - 仅授权短信发送所需权限（至少 `QcloudSMSFullAccess`，更小权限按腾讯云策略细化）；
   - 生成 **SecretId / SecretKey**，只写入服务器 `shared/.env`，**绝不进版本库**。
7. **网络**
   - 服务器需能访问 `https://sms.tencentcloudapi.com`（出网 443）。

## 3. 服务器配置

编辑 `/opt/cw-tc/shared/.env`（`chmod 600`，由 systemd `EnvironmentFile` 注入）：

```bash
CWTC_SMS_PROVIDER=tencent
CWTC_SMS_SECRET_ID=你的SecretId
CWTC_SMS_SECRET_KEY=你的SecretKey
CWTC_SMS_SDK_APP_ID=1400xxxxxx
CWTC_SMS_SIGN_NAME=畅网智能科技
CWTC_SMS_TEMPLATE_ID=1234567
CWTC_SMS_REGION=ap-guangzhou
```

可选调整（当前代码使用默认值）：

- 单手机号每日上限：代码默认 10
- 60 秒冷却：代码默认
- 单 IP 每小时上限：路由中间件默认 20

修改后重启服务：

```bash
sudo systemctl restart cw-tc-server
sudo systemctl status cw-tc-server --no-pager
```

## 4. 验证步骤（上线前必须做）

1. **单元测试**（不依赖真实密钥）：

```bash
cd packages/server
go test ./internal/sms/... ./internal/api/ -run 'TestTencentSend|TestSendSMS' -v
```

2. **真实发送**（在服务器或能访问腾讯云 API 的本机）：

```bash
# 1) 取图形验证码
curl -s -X POST https://<你的域名>/api/v1/auth/captcha -H 'Content-Type: application/json' -d '{}'

# 2) 用返回的 captcha_id + 任意验证码答案调用发送（图形验证码只在开发测试允许 test；
#    生产请按 App 实际页面操作）
curl -s -X POST https://<你的域名>/api/v1/auth/sms/send \
  -H 'Content-Type: application/json' \
  -d '{"phone":"13812345678","scene":"login","captcha_id":"<captcha_id>","captcha_answer":"<页面答案>"}'
```

3. **逐项验收**
   - [ ] 返回 `code=0` 且手机收到短信；
   - [ ] 60 秒内再次发送被拒（429）；
   - [ ] 同一手机号第 11 次/日被拒（429）；
   - [ ] 错误 Secret / 模板错误 → 返回 502，且刚生成的验证码不可用；
   - [ ] 未配置渠道时返回 503（**不静默成功**）；
   - [ ] 短信内容**不回显到响应 / 日志**；
   - [ ] 用收到的验证码完成登录 / 注册 / 重置流程；
   - [ ] 站内消息中心、事务通知、广播**仍正常**（未被短信渠道影响）。

## 5. 回滚

- 删除或注释 `CWTC_SMS_PROVIDER` 后重启：短信发送立即变为 fail-closed（503），
  **其他业务与站内通讯不受影响**。
- 不在代码里保留任何默认 Secret；密钥只存在 `shared/.env`。
