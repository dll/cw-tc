# 第三课堂 · 数据字典（v1）

> 配套：`docs/PRD-第三课堂-v2.md` §8（数据模型）· `docs/API接口参考-v1.md`（接口契约）。
> 本文是**建表与写 migration 的唯一定义** —— 字段类型、约束、索引、枚举以本文为准。

| 项 | 内容 |
|---|---|
| 版本 | **v1.7**（v2.11 AI 生成内容：草稿 / 双审记录 / `lecture.origin`） |
| 日期 | 2026-10-03 |
| 数据库 | PostgreSQL 15+（扩展：`pgvector`） |
| 命名 | 表 / 字段一律 **`snake_case`**；主键 `id bigint generated always as identity` |
| 时间 | 一律 **`timestamptz`（UTC）**；展示按 `Asia/Shanghai`（PRD v2 §11.6） |
| 枚举 | 一律**小写英文**，落库为 `text` + `CHECK`（不建独立枚举类型，便于演进） |
| 金额 | 一律 **`bigint` 分为单位**（`*_cents`）—— **绝不用浮点** |
| 金额币种 | 人民币（`CNY`），首发不支持多币种 |
| 软删 | **一律逻辑删除或状态标记，不做物理删除**（证书、订单、流水永久留存） |

## 2. 账号与实名

### 2.1 `student`（学员）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | |
| `student_no` | text | **UNIQUE NOT NULL** | `TC2026-000137`；**平台内部编号，不是账号** |
| `name` | text | NOT NULL | 证书署名；**不可自助修改** |
| `phone` | text | **UNIQUE NOT NULL** | **登录账号**；换绑即改此值 |
| `phone_verified_at` | timestamptz | | 号码可用性验证时间 |
| `id_card_hash` | bytea | **UNIQUE NOT NULL** | `HMAC-SHA256(身份证号, CWTC_ID_CARD_HMAC_KEY)`；**不用于登录** |
| `id_card_cipher` | bytea | NOT NULL | `AES-256-GCM` 密文（含随机 IV 与 tag）；**仅制证时解密** |
| `id_card_enc_key_id` | smallint | NOT NULL DEFAULT 1 | **密钥版本**（轮换用，见 PRD v2 §12.2） |
| `password_hash` | text | | argon2id / bcrypt；验证码登录用户可空 |
| `password_updated_at` | timestamptz | | |
| `status` | text | NOT NULL DEFAULT `'active'` | `active` 正常 / `limited` 临时限制 / `suspended` 停用 / `banned` 永久封禁 / `deleting` 注销处理中 / `anonymized` 已匿名化 |
| `status_reason_kind` | text | | **v2.6**：`sms_abuse` / `payment_abuse` / `identity_mismatch` / `exam_fraud` / `serious_violation` / `login_fail` |
| `status_note` | text | | **v2.6**：说明（**封禁必填**，学员可见） |
| `status_until` | timestamptz | | **v2.6**：期限；`null` 且 `status='banned'` = 永久 |
| `status_by` | bigint | FK → staff | **v2.6**：操作人；系统自动为 `null` |
| `failed_login_count` | int | NOT NULL DEFAULT 0 | 失败锁定计数 |
| `locked_until` | timestamptz | | 失败锁定到期（自动，与 `status='limited'` 配合） |
| `created_at` / `updated_at` | timestamptz | NOT NULL DEFAULT now() | |
| `last_login_at` | timestamptz | | |
| `agreement_versions` | jsonb | NOT NULL | `[{"doc":"privacy_policy","version":"v1.0","agreed_at":"..."}]` |

**索引**：`UNIQUE(phone)`、`UNIQUE(id_card_hash)`、`UNIQUE(student_no)`、`INDEX(created_at)`。

> ⚠️ **不得**出现学号字段（PRD v2 §7.1 A-5）。
> ⚠️ **明文身份证号绝不落库**（铁律 3）；`scan-sensitive.sh` 会扫代码与日志。
>
> **账号状态规则（v2.6，PRD §7.10.10（三））**：
> - **谁能改**：`limited` 由系统自动；`suspended` 由 ops；**`banned` 仅 super**；
> - **封禁必填** `status_reason_kind` + `status_note`，**并写 `audit_log`**；
> - **学员侧必须可见**：登录时返回"已停用 + 原因类别 + 申诉入口"，
>   **不得只返回 401**（否则等于"莫名登不上"，客服会被问爆）；
> - **解封**：ops 可解封（`banned` 需 super）；**解封不恢复已撤销证书、不恢复已退款订单**。
>
> **注销后（`anonymized`）**：`name` 匿名化、`phone` 置空、`id_card_cipher` 与 `id_card_hash` **删除**；
> `student_no` 与证书台账**保留**（编号要能追溯）。
> ⚠️ 因此 `phone` 的唯一约束**必须允许空值**（PostgreSQL 的 `UNIQUE` 天然允许多个 `NULL`，
> 但若用空串请改用 **部分唯一索引** `UNIQUE(phone) WHERE phone IS NOT NULL AND phone <> ''`）。

### 2.2 `student_session`（会话）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | |
| `student_id` | bigint | FK → student | |
| `token_hash` | bytea | **UNIQUE NOT NULL** | 只存 token 的哈希，**不存原文** |
| `issued_at` / `expires_at` | timestamptz | NOT NULL | 有效期 ≤ 7 天 |
| `user_agent` / `ip` | text / inet | | 风控与"登出全部设备"用 |
| `device_type` | text | CHECK | `app` / `web`（**v2.5**：设备列表展示用） |
| `device_name` | text | | **v2.5**：如「iPhone 15 / Chrome on Windows」，**只存服务端推断值，不采集设备指纹** |
| `last_active_at` | timestamptz | | **v2.5**：设备列表"最近活跃" |
| `revoked_at` | timestamptz | | 非空即失效（登出 / 踢出 / 改密批量置位） |

> **多设备策略（v2.5）**：**同账号允许多会话并存**（学员手机 + 电脑同时用），
> **不做单设备互踢**；改密 / 登出全部 → **该学员全部会话置 `revoked_at`**（≤ 1 分钟内生效）。

### 2.3 `staff`（教师 / 管理员）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | bigint | PK | |
| `account` | text | **UNIQUE NOT NULL** | 后台账号（非手机号） |
| `name` | text | NOT NULL | |
| `role` | text | NOT NULL CHECK | `teacher` / `admin_ops` / `admin_super` |
| `phone` | text | **UNIQUE** | **v2.5 新增**：staff 也绑手机号（找回与异常登录告警） |
| `password_hash` | text | NOT NULL | **首登强制改密** |
| `password_changed_at` | timestamptz | | 为空 = 仍是初始密码，**登录后强制跳改密** |
| `created_source` | text | NOT NULL CHECK | `seed`（种子命令）/ `admin`（管理员开通） |
| `created_by` | bigint | FK → staff | 种子创建时为 `null` |
| `status` | text | NOT NULL DEFAULT `'active'` | `active` / `disabled`（**停用后保留数据**） |
| `created_at` / `updated_at` | timestamptz | | |

> **无自助注册入口**：种子管理员由 `cw-tc-server seed-admin` 创建（幂等）；
> 教师账号只能由管理员开通（PRD v2 §8.2 开通路径）。
>
> **管理员分级（v2.5）**：`admin_super` 可创建 / 停用管理员、改系统配置、导全量数据；
> `admin_ops` 业务全权但**不可**做上述三件事（PRD §7.10.5）。
> **硬约束：`admin_super` 至少 1 个** —— 用触发器或应用层校验拦截
> "停用 / 降级最后一个超管"，**否则后台会永久锁死**。
>
> **教师停用（v2.5）**：`status='disabled'` 后**不删除**；其课程必须先**移交**
> （改 `course.teacher_id`）或**下架**，且**待阅卷队列必须清空**（PRD §7.9 J-9）。

## 9. 必须由数据库 / 应用层兜住的约束（**不靠代码自觉**）

| # | 约束 | 形式 | 防的是什么 |
|---|---|---|---|
| 1 | 一人一号 | `UNIQUE(phone)` + `UNIQUE(id_card_hash)` | 重复注册、一人多号 |
| 2 | **一次课程只付一次钱** | `UNIQUE(student_id, course_id) WHERE status='pending'` | **连点下单导致重复支付** |
| 3 | **无据不答** | `CHECK (outcome <> 'answered' OR citations IS NOT NULL)` | AI 编造无出处的回答 |
| 4 | 同课同级只发一张 | `UNIQUE(student_id, course_id, level) WHERE revoked_at IS NULL` | 重复发证 |
| 5 | 当前有效权益唯一 | `UNIQUE(student_id, course_id) WHERE revoked_at IS NULL` | 权益叠加错乱 |
| 6 | **同一个待处理申请不重复**（v2.5） | `UNIQUE(course_code, kind) WHERE status='pending'` | 教师连点提交一堆下架申请 |
| 7 | **超管至少 1 个**（v2.5） | **应用层事务校验**（DB 难表达） | 停用 / 降级最后一个超管导致**后台永久锁死** |

> **第 7 条为什么必须做**：这是"能把系统锁死"的少数操作之一 ——
> 没有超管，就没人能再开管理员、改配置。数据库唯一约束表达不了"至少一条"，
> 故放在应用层，**在一个事务里先查计数再更新**（并发下要加行锁）。
